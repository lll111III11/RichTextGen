🧠 AI 大脑

上下文与单次输出默认取接口上限（不限制）；对话过长时会自动压缩旧上下文继续，无需手动配置。思考强度请到「✦ AI 对话」窗口的底部滑动条调节。

DeepSeek → thinking + reasoning_effort；通义千问 → enable_thinking + thinking_budget；Kimi → reasoning_effort / thinking.keep；智谱 GLM → thinking.type + reasoning_effort；OpenAI → reasoning_effort。
