互动由模型目录里的 model.json 驱动：点击 / 悬停不同部位会触发台词和动作，闲置时会自己闲聊。可以直接改文件，也可以让 AI 根据角色图片生成整套配置（需先在「AI 接入」里填好 Key；视觉模型还能看图猜性格）。
配置写法（regions / actions / idle）与模型格式说明 
{
  "name": "角色显示名",
  "regions": [
    {"x": 0.30, "y": 0.03, "w": 0.40, "h": 0.30,
     "click": ["pat"], "hover": ["notice"]}
  ],
  "actions": {
    "pat": {
      "say": ["别摸头啦～", "再摸一下也可以…"],
      "anim": {"bounce": 8, "spin": 0, "wobble": 5},
      "duration": 600, "cooldown": 1200
    }
  },
  "idle": {"chatter": ["今天也要加油哦～"], "every": 150}
}

· x / y / w / h 都是 0~1 的相对位置，左上角为原点。
· say 是台词（字符串或数组，随机抽一句）；bounce 弹跳像素，spin / wobble 旋转角度。
· cooldown 冷却毫秒，防止连点刷屏；idle.every 是闲聊间隔秒数。
· 3D 模型：目录里放 model.glb 或 model.vrm（单文件，VRM 按 glTF 渲染）。
  首次使用先点「下载 3D 组件」（three.js，约 700KB），之后可离线使用。
· Cubism（.moc3）：用「导入模型文件夹…」选整个模型包（含 .model3.json / .moc3 / textures）。
  首次先点「下载 Cubism 组件」（Cubism Core + PIXI，约 1.5MB）。Core 由 Live2D 官方提供，
  使用即表示同意其许可条款；本程序不内嵌这些组件。

系统集成（打开方式 / 右键菜单）

注册后会写入：① 任意文件右键 →「用彩色文本生成器打开」；②「打开方式」列表中出现本程序；③ 只接管最常用的 6 种文本格式：TXT / MD / LOG / JSON / INI / CSV（不再一次性塞进三十多个扩展名）。
Windows 10/11 不允许程序静默抢默认打开方式：想双击 TXT 直接进本程序，请点上面的「打开系统默认应用设置」，把 .txt 的默认应用选成本程序（只需设置一次）。之后资源管理器右键菜单里也会像记事本一样出现本程序入口。
