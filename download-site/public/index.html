下载时出现安全提示？

从 GitHub 下载
  • 浏览器提示「不常见的下载内容 / 可能有害」：在下载项菜单里选择「保留」或「仍要下载」即可。
  • SmartScreen 提示「Windows 已保护你的电脑」：点「更多信息」→「仍要运行」。若只看到「删除」，先点提示框左侧的「更多信息」。
  • 为什么会被拦：安装包由项目自有的代码签名证书签名，不是付费商业 CA 签发，Windows 与浏览器因此会给出警告。这只说明证书未受信任，不代表文件被篡改。
  • 怎么确认没被改过：展开卡片里的「SHA-256 校验值」，用 certutil -hashfile 文件名 SHA256 比对；或改从 GitHub Releases 下载同一文件交叉核对，源码也都在这个仓库里。
