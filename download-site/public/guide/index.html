1. 快速开始

彩色文本生成器是一个 Windows 桌面文本工具：左侧是编辑区，右侧是「工作台」，把颜色、样式、图片、翻译、AI 等能力集中在一起。

  1. 安装版双击 RichTextGen-Setup.exe，按向导装到当前用户目录（不需要管理员权限）；免安装版解压 RichTextGen-Portable.zip 后直接运行 彩色文本生成器.exe。
  2. 首次启动会弹出简短提示，说明后台常驻、标签拆分与注册范围，可勾选「不再提示」。
  3. 在左侧输入内容；选中文字后，在右侧工作台点颜色或样式即可上色。
  4. 多个文件想同时开着，用「文件 → 新建标签页」，或把标签拖到窗口外拆成独立窗口。
双击由本程序接管的文本文件（.txt / .md / .log / .json / .ini / .csv）时，会先出现一个干净的浅色窗口，界面加载完再自动填入内容，不需要等待白屏。

4. 菜单详解

4.1 文件

  • 新建标签页 / 新建窗口：开一份新文档，或干脆开一个新窗口。
  • “新建 Markdown”选项卡：直接建一个 .md 标签并预填标题骨架。
  • 打开…：选择本机文本文件。打开过的文件会出现在最近使用里，可直接重开。
  • 保存 / 另存为 / 全部保存：保存会保留原编码与换行符；多个标签一次写入用「全部保存」。
  • 页面设置 / 打印：设置页边距（毫米），打印时生效。
  • 关闭选项卡 / 关闭窗口 / 退出：注意「关闭窗口」按你设置的关闭行为处理（最小化到托盘或退出）。

4.2 编辑

  • 撤销 / 重做 / 剪切 / 复制 / 粘贴 / 删除：常规编辑操作。
  • 清除格式设置：在渲染模式下清掉选区的颜色与样式。
  • 使用必应搜索：选中文字后直接用默认浏览器搜索。
  • 查找 / 查找下一个 / 查找上一个 / 替换 / 转到：会打开编辑器上方的查找条。
  • 时间/日期：在光标处插入 2026-10-24 22:02:23 这样的时间。
  • 字体…：调整编辑区字体、字号、加粗与斜体。

4.3 查看

  • 缩放：放大 / 缩小 / 还原默认缩放（60%–200%）。
  • 状态栏：显示或隐藏底部状态栏。
  • 自动换行：长行是否折行显示。
  • Markdown：预留项，暂为灰色不可用。

4.4 格式 / 帮助

  • 格式：跳到工作台的颜色系统、样式与渐变、拾色器，以及「切换渲染模式」。
  • 帮助：立即检测更新、查看发布页、Android 版说明、关于。

5. 编辑器：源码与渲染、查找与替换

编辑器上方有两个按钮：

  • 源码：显示真正的文本，包括 <color=#FF6B81> 这类标签。要精确改标签、做替换，用这个模式。
  • 渲染：按标签实时显示颜色与样式，所见即所得。选中文字后在工作台点颜色，改动会写回源码。
  • Ctrl+F 查找，Ctrl+H 替换，Ctrl+G 转到行号。
  • F3 / Shift+F3 跳到下一个 / 上一个匹配。
  • 替换与转到行在源码模式下执行；渲染模式会提示切换。

6. 功能页说明

6.1 生成

「生成」页是一个入口提示，真正的颜色与样式生成在工作台主页完成：选颜色 → 套到选区，或按行批量上色。

6.2 图片

把图片直接拖进窗口，或在面板里选择图片，程序会把像素转成彩色方块字符并带上 <color> 标签，适合做头像、logo 的文本化版本。

6.3 在线翻译

  1. 选择翻译服务，按提示填写 Endpoint 与 API Key（保存在本机）。
  2. 选择源语言与目标语言，点「翻译工作台文本」。
  3. 文本里的 <color> 等标签会被保护，不会被翻坏。

6.4 AI 对话

点「AI」会打开独立的对话窗口：左侧是任务列表，底部输入框可选模型、思考强度与联网搜索。窗口独立存在，可以一边看文档一边对话。首次使用需要在设置里填写模型服务与密钥。

AI 也可以直接操作工作台：例如让它「把这段文字改成蓝色渐变、加粗、字号 48」，它会生成对应的标签并套用到选区。

6.5 TXT 全面处理

把长文本拆成一行一条，适合批量给每行上色、批量加前缀后缀。按钮包括：从工作台载入、导入 TXT、全选 / 全不选、复制选中行、导出 TXT、回填工作台。

6.6 音乐

支持 mp3 / wav / ogg / m4a / flac / aac / wma / opus。拖入后程序会在本机起一个只读端口，生成一个可直接放进播放器或网页的链接；程序关闭后链接失效。

8. 彩色标签写法与示例

文本使用 Unity / TextMesh Pro 风格的标签。最简单的上色方式是用工作台点颜色；也可以直接手写：

这是 <color=#FF6B81>红色</color> 与 <color=#3DDC97>绿色</color>， 还有 <color=#6EA8FF>蓝色</color>。

渲染后就是：

这是 红色 与 绿色，还有 蓝色。

常用写法

写法效果
<color=#FF6B81>文字</color>指定颜色
<b>文字</b>加粗
<i>文字</i>斜体
<u>文字</u>下划线
<size=48>文字</size>指定字号
标签必须成对闭合（<color> 配 </color>）。在渲染模式下删除彩色文字时，建议先切回源码模式，避免把标签拆断。

10. 安装、更新与安全提示

安装位置与权限

安装版默认装到 %LOCALAPPDATA%\Programs\RichTextGen，只写当前用户注册表，全程不弹 UAC。安装过程也不会向系统证书存储写入任何证书。

下载或安装时的安全提示

安装包使用项目自有证书签名，不是付费商业 CA 签发，因此浏览器与 Windows 可能给出提示。这只说明证书未受信任，不代表文件被篡改。
  • 浏览器提示「不常见的下载内容」：在下载项里选「保留」或「仍要下载」。
  • SmartScreen 提示「Windows 已保护你的电脑」：点「更多信息」→「仍要运行」。
  • 核对方式：在下载页展开「SHA-256 校验值」，用 certutil -hashfile 文件名 SHA256 比对；或改从 GitHub Releases 下载同一文件交叉核对。

更新机制

程序会同时探测 Cloudflare 下载站 与 GitHub 两条通道，哪条快用哪条；手动点「立即检测更新」默认走 Cloudflare；任一通道下载失败会自动换另一条。
